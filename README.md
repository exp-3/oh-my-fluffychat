# Oh-My-FluffyChat

[FluffyChat](https://fluffychat.im) is an open source, nonprofit and cute [[matrix](https://matrix.org)] client written in [Flutter](https://flutter.dev). The goal of the app is to create an easy to use instant messenger which is open source and accessible for everyone.

## About this fork

Oh-My-FluffyChat was originally developed for personal use. It adds novel, practical features and fixes some 100% human-made issues and bugs. Almost all additions and modifications made in this fork were generated by artificial intelligence (AI).

The source code and distributed binaries are provided "as is", without warranties of any kind, express or implied. For serious or critical use, please consider the [original upstream FluffyChat project](https://github.com/krille-chan/fluffychat).

# Features

## Upstream features

- 📩 Send all kinds of messages, images and files
- 🤙 Video calls with Matrix RTC
- 🎙️ Voice messages
- 📍 Location sharing
- 🔔 Push notifications
- 💬 Unlimited private and public group chats
- 📣 Public channels with thousands of participants
- 🛠️ Feature rich group moderation including all matrix features
- 🔍 Discover and join public groups
- 🎨 Material You design
- 😄 Custom emotes and stickers
- 🌌 Spaces
- 🔐 End to end encryption
- 🔒 Encrypted chat backup
- 😀 Emoji verification & cross signing
  ... and much more.

## Oh-My-FluffyChat features

- 🌐 Manual and automatic message translation, input translation, and customizable bilingual display
- 🔌 Configurable translation providers using Chat Completions, Responses, or Anthropic Messages APIs
- 🔄 Shared local translation cache across accounts, with optional encrypted roaming via Redis or Upstash-compatible services
- 🖼️ Configurable image sending with format conversion, maximum dimensions, and AVIF support where available
- 🔎 Enhanced room history search with incremental results, pause and resume, and collapsible progress controls
- 🎨 Optional gradient message bubbles

# Installation

Download builds of this fork from the [Oh-My-FluffyChat Releases](https://github.com/exp-3/oh-my-fluffychat/releases) page. Available packages can vary between releases; use the assets and instructions listed for the release you choose.

| Platform | Release asset | Installation |
| --- | --- | --- |
| Android | APK for `arm64-v8a`, `armeabi-v7a`, or `x86_64` | Install the APK matching your device's architecture. |
| Windows | x64 installer (`fluffychat-windows-x64-setup.exe`) | Run the installer. |
| Linux | Package or archive for x64 or arm64 | Choose your architecture and follow that release's installation or extraction instructions. |
| Web | Web archive (`fluffychat-web.tar.gz`) | Extract the web build and serve it under `/web/` on your own web server. |

When a prerelease provides debug artifacts, download them from its corresponding [Release Builds workflow run](https://github.com/exp-3/oh-my-fluffychat/actions/workflows/release.yaml). These artifacts are retained temporarily.

The upstream website at [fluffychat.im](https://fluffychat.im) provides installation options for the original FluffyChat project.

# Configuration and Mobile Device Management (MDM)

FluffyChat supports configuration via MDM on Android&iOS (since v2.10.0) and via a config.json file on web. You can see the populated configuration for MDM on Android in this file under `/android/app/src/main/res/xml/app_restrictions.xml`.
An example configuration can be found in the `config.sample.json` file.

# How to build

To build this fork on your own development machine, use the [Flutter](https://flutter.dev) version pinned in [.fvmrc](.fvmrc), [Rust stable](https://www.rust-lang.org/tools/install), and the native build tools required by your target platform. The [release workflow](.github/workflows/release.yaml) records the platform dependencies and packaging steps used by this repository.

Clone this repository and resolve its dependencies:

```sh
git clone https://github.com/exp-3/oh-my-fluffychat.git
cd oh-my-fluffychat
flutter pub get
```

Run the app on a configured native target with:

```sh
flutter run
```

For web development, complete the preparation step below before running or building the app.

### Web

The web preparation script requires a POSIX shell, Git, `curl`, `unzip`, `yq`, and GNU-compatible `sed` (`gsed` on macOS), in addition to Flutter. From the repository root, prepare the web assets and worker scripts:

```bash
./scripts/prepare-web.sh
```

Then use `flutter run -d chrome` for development or `flutter build web --release` to produce a web build.

- Optionally configure by serving a `config.json` at the same path as fluffychat.
  An example can be found at `config.sample.json`. All values there are optional.
  **Please only the values, you really need**. If you e.g. only want
  to change the default homeserver, then only modify the `defaultHomeserver` key.

## How to run integration tests

You need to have docker installed locally! Run the preparation script before every test run:

```sh
./scripts/prepare_integration_test.sh
```

Then run all tests with:

```sh
flutter test integration_test/mobile_test.dart
```
